Oaink helps reviewers understand a pull request inside VS Code. It organizes a change around symbols and
behavior, brings together structural analysis, and links review evidence to the code it describes. The reviewer
keeps control of what to inspect and what feedback to leave.

The project is being prepared for release. Structural review remains free. Pro adds Lens explanations and
conversation, MCP review tools for a user's own agent, and CLI review commands for local automation and CI.
Model access is bring-your-own-key; an Oaink subscription does not include model inference credit.

Pro launch pricing is planned at $5 per month or $40 per year, with an early-customer offer of $20 for the first
year, renewing at $40 per year. Purchase availability will be announced on the Oaink site.
